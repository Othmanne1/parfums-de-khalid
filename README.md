# Parfums de Khalid — site statique

Fichiers créés:

- `index.html` — page principale
- `styles.css` — styles
- `script.js` — logique du panier et envoi WhatsApp

Usage rapide:

Ouvrez `index.html` dans un navigateur. Pour finaliser les images produit, remplacez les URL dans `script.js` (const `PRODUCTS`) par des images réelles.

Le bouton de commande ouvre WhatsApp vers le numéro `+212712233293` avec le récapitulatif et les informations client.

Chaque produit dispose désormais d'une page de détails séparée : cliquez sur le bouton **Détails** pour ouvrir `product.html?id=<id>`, voir plus d'informations et ajouter directement le produit au panier.

Pour modifier les images, le titre du hero, le texte et le numéro WhatsApp, utilisez `config.html`. Enregistrez la configuration et rechargez `index.html` pour appliquer les changements.
